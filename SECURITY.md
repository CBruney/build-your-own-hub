# Private data and account boundaries

The distributed example contains fictional data and performs no external actions. The local server binds to 127.0.0.1 and exposes only explicitly allowed demo files. It is not a production server.

Do not put real credentials, work messages, home controls, or personal source snapshots in a publicly served directory. A customized copy requires its own privacy review. Browser storage is local convenience storage, not an encrypted vault or shared database.

If you discover a problem in this starter, share a minimal fictional reproduction directly with the person who supplied your copy. Do not post real account data, logs, or tokens in a public issue. Disable an affected connected feature in your own implementation while investigating; preserve evidence without replaying actions.
